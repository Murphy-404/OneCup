# 私人工具版路线图

v0.3：无登录、单用户实例，服务端 SQLite 与 Docker 数据卷持久保存。个人非商业使用并要求标注来源。

## P0 已实现，持续验证

参考配方、材料器具、替代自制、分步制作、私人快照、备料与备份；新增结构化自建配方编辑器、未完成草稿、制作校验、私人合集的固定快照、排序复制导出、显式更新来源，以及 v1→v2 数据迁移。部署包含 Node API、数据库一致性快照和恢复，不支持纯静态保存。

## P1

- 已实现：咖啡工作台记录可在自制浓缩向导中选择，保存参数快照；重量和体积分别测量，不把目标粉液比当投入水量。
- 已实现：相同规格基底合批与剩余量，未知产量不推测；自动化测试覆盖规格隔离。
- 待实做：少量真实试调与材料规格验证。无法通过代码测试宣称饮品已试做。

## P2，待另行实现

PWA 安装、离线缓存与制作中断恢复；有实测模型依据的杯容量适配；更多示意图。暂不承诺后台计时和原生 App。

## 人工验收待办

实体手机、真实反向代理和目标机器的离机恢复演练。浏览器尺寸模拟不能替代实体设备验证。

## 排除

登录、公开作者、社区、分享页、关注评论私信、广告和付费服务。自营社交版不在本仓库的交付范围。
