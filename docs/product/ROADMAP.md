# 私人工具版路线图

本文件描述计划，不代表功能已实现，也不承诺交付日期。许可为个人非商业使用并要求来源标注。

## 现在可以使用

参考配方、分类搜索、主动随机、材料与器具、有限替代和自制、逐项撤销、分步制作、计时、完整图片与部分杯型、收藏、私人版本、备料、咖啡计算与记录、JSON 备份恢复。

v0.2 按产品决定移除登录、服务端账号和数据库，使用浏览器 IndexedDB；提供 Docker 单容器静态部署。账号与云同步不在此版本路线内。

## P0：独立私人工具体验

- 自建配方编辑器：从空白创建结构化配方，保存未完成草稿，制作前校验材料与步骤引用。
- 私人配方合集：命名、排序、固定条目快照，与收藏和备料清单分开。
- 格式升级：兼容既有 v1 记录，导入失败不覆盖原数据，新增对象有独立回归测试。
- 改善仅运行前端时的服务状态与账号入口说明。
- 干净环境部署、备份恢复和实体手机任务复测，继续核对配方与替代的实做结果。

## P1：加强复现能力

- 咖啡参数记录与自制咖啡液入口之间的完整衔接。
- 多杯同规格基底合批、剩余量和未知产量表达。
- 小批经过实际试做的配方、材料规格与替代规则。

## P2：按需求扩展

- PWA、完整离线缓存与制作中断恢复。
- 有可靠模型和实测依据的容器容量适配。
- 更多示意图与辅助展示，不优先于计算和制作体验。

## 不纳入本仓库

公开作者资料、用户作品发布、公共合集分享、动态、关注、评论、私信、广告、付费订阅与商用托管服务。
