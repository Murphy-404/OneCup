# 配方图片

参考配方各保留一张 AI 示意图，可查看完整图片与放大，不再切换容器。

进入“我的做法 → 自建与合集”，新建或编辑自建配方，在“配方图片”中上传、更换或移除图片，再保存草稿或可制作配方。支持 JPG、PNG、WebP，原图不超过 10 MB；HEIC、GIF、SVG 暂不支持。未上传时显示占位，不借用参考配方图片。

图片会在浏览器中按原比例缩小为最长边不超过 960px，并重新编码为不超过 64 KiB 的 WebP/JPEG。处理期间不能保存；处理失败保留旧图片和其他输入。这里只保存处理后的图片，不保存原文件名和原始元数据。

保存后，图片跟随配方进入服务器 SQLite 或 Cloudflare D1，JSON 和数据库备份也包含图片，无需额外图床。以页面显示保存成功为准。公开只读演示不能上传和保存，需要部署自己的实例。

已有做法、备料和合集使用固定快照，包括当时的图片。修改或移除源配方的图片不会改变旧快照；合集可在确认后更新来源。

图片和重复快照都会占用工作区空间，本版本工作区请求上限约 5 MB。超限会在保存前提示并保留当前输入，可先导出备份，再减少不需要的图片或快照。导出文件包含私人图片，请按自己的数据保管。
