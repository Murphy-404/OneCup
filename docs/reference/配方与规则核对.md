## 首批试做候选与记录

建议先做冰燕麦拿铁、冰抹茶拿铁、菠萝气泡饮、威士忌高球，各覆盖一类；这是待办，不标为已推荐或已验证。茶汤浓度、糖浆品牌、奶泡和近似替代效果的标准化需要实际记录。试做不通过可缩小正式推荐目录。

每次记录：

- 配方 ID、内容版本、规则 ID/版本、日期与试做者。
- 材料品牌/规格、实际质量/体积、糖浆浓度、茶叶与茶水比例。
- 器具型号、咖啡粉量/研磨/水温/时间/出液体积或质量（分开记录）。
- 前置、调配、冷却分别耗时；实际产出、杯容量和剩余。
- 风味、甜酸、质地、分层和泡沫观察；调整前后用量。
- 实拍证据、问题、复测结论。未记录不得改为已试做。
